## usage

```
$ cargo run -- -f /path/to/program -o /path/to/output
```

### command line option
| option | explanation |
| --- | --- |
| `-h, --help` | Show help |
| `-f, --file <FILE>` | Set the input file |
| `-o, --output <OUTPUT>` | Set the output file |
| `--no-timestamps` | generate CHCs without timestamps |
| `--deadlock` | generate CHCs for deadlock detection |
| `-e, -exec` | execute input program |
